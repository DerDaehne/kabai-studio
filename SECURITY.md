# Security Policy

## Supported Versions

Early development, no releases yet — only the latest commit on `main` is
supported.

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub's
[Private Vulnerability Reporting](https://github.com/DerDaehne/kabai-studio/security/advisories/new)
("Report a vulnerability" under this repository's Security tab).

Do not open a public issue for security vulnerabilities.
